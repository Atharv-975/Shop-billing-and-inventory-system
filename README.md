# Fresh @ Shop - Billing and Inventory System

# Project Overview

*Fresh @ Shop - Billing and Inventory System* is a beginner-friendly
Python project for managing products, stock, and customer bills in a
small shop.

The program is menu-driven and allows the shop user to view products,
search products, add new products, update stock, and generate customer
bills.

# Features

- View all available products
- Search a product using Product ID
- Add a new product
- Update product stock
- Generate a customer bill
- Automatically reduce stock after a sale
- Apply discount according to the bill amount
- Select payment mode
- Display current date on the bill
- Show shop name and phone number
- Handle invalid product IDs, quantities, and menu choices

# Discount System

  Bill Amount            Discount
  -------------------- ----------
  Below Rs 1500                0%
  Rs 1500 to Rs 3999           2%
  Rs 4000 and above            4%

# Payment Modes

The customer can select: 1. Cash 2. UPI 3. Card

# Main Menu

1. View inventory

5. Generate customer bill
